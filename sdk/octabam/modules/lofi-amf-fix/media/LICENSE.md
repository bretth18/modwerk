# Media rights

`ot-*.png` are captures of the native Octatrack LCD, rendered in monochrome by `scripts/capture-module-ui.py` from the headless `ot_emu` for module documentation. Bryan Tysinger ran the capture; the panel plan and `capture.json` record are Modwerk contributors' work. The screens are stock OS 1.40C pages, unchanged by this module. The underlying Octatrack interface remains Elektron material; no relicensing of that interface is claimed. Use is declared as `LicenseRef-OT-UI-Documentation` for review in this repository. Firmware, cards, raw LCD planes and memory dumps are not distributed.

`presentation/thumbnail.svg` is original Modwerk artwork under the module's MIT terms.
