# DIGISLICER

DIGISLICER is the SLICE machine with a slice editor. Its SRC page is SLICE’s; press SRC again for a waveform view where you add, split, delete and move slices, auto-slice on transients or use equal grids, watch them play and play them from the trig keys. A sample’s own slices play on every DIGISLICER track and are kept per sample on the +Drive. GRID gains AUTO (slices on the transients) and PLAY gains PIPO (ping-pong loops). With the keyboard on, the trig keys play the slices one per key, as the Octatrack’s trig slice mode, and live recording records them as slice locks. The stock SLICE machine is left as it is.

By irpina (@irpina) · GPL-2.0-or-later · Digitakt OS 1.53, 1.54 · imported from [irpina/digislicer](https://github.com/irpina/digislicer/tree/ac0c46d8607205352adcd0f49fb09a4736edda17) at v2.1.

## Where to find it

SRC machine list, below SLICE.

1. Select a track, press FUNC + SRC and choose DIGISLICER below SLICE.
2. Press SRC again to open the slice editor; SRC, NO or another page key closes it.

## Controls

| Control | What it does |
| --- | --- |
| Knob A | Select a slice in the editor |
| Knob B | Move the slice start |
| Knob C | Move the start by single samples |
| Knob D | Zoom horizontally around the cursor |
| Knob H | Zoom vertically, up to 64 times |
| LEVEL | Move the cursor; the waveform scrolls with it |
| FUNC + YES | AUTO SLICE |
| YES | Open the slice menu |

## Limitations

- Slices are stored on the +Drive in /cfw/slices.a and /cfw/slices.b; a /cfw folder appears in the sample browser.
